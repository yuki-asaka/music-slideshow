# 写真の選定

## 流れ

1. `convert_photos.py` → `fix_orientation.py` → `make_sheets.py` で、行事ごとのコンタクトシート（1枚48コマ、`work/sheets/<行事>_NN.jpg`）と `data/photo_stats.csv` を作る
2. シートを Read で見て、全写真に目を通す（行事ごとに数枚のシート）。`photo_stats.csv` の `sharp`（小さいとブレ）・`bright`・`orient`・`group`（似た写真のまとまり）も参考にする
3. シナリオ（design.md 4.3）の枠ごとに、候補を選ぶ
4. `selection.csv` に書き、`preview_selection.py` で割り付け順の一覧画像を作って見直す
5. 書き出したフレーム（`export.py frames`）で、顔が切れていないかを確かめる

## 選ぶ基準

- 表情がよい（笑顔・真剣な顔）。ブレ・ピンぼけ・目つぶりがない
- 似た写真（同じ `group`）が続くなら1枚に絞る
- 集合写真・少人数のアップ・引きの全景を混ぜる。集合写真は役割のある場所だけ（scenario-design.md 7）
- 枠の役割に合わせる
  - 章の導入: 行事が始まると分かる引きの写真（入場・全景・黒板・看板）
  - 章タイトルが重なる写真: 左下（章タイトルの帯）に顔がない
  - 半小節: 一目で分かる動き・表情のアップ
  - 2小節以上: 集合写真・細かい情報のある写真
  - コラージュ: 縦向きの写真3枚（または縦長に切って成り立つ写真）
  - グリッド: 少人数や集合の笑顔。本編と重なってもよい。行事が偏らないように混ぜる
  - アウトロのマッチディゾルブ: 並びと構図が近い2枚
- 講演・発表の行事は、講師やスクリーンが大きく写る写真が多い。生徒が写る体験・交流の写真を中心にする
- 先生が写る写真を行事の中にも入れる

## 16:9 に切るときの注意

4:3 の写真（3840×2880）は、画面の横幅に合わせると上下が 12.5% ずつ切れる。

- 顔が写真の上端や下端に近い写真は、`crop=0,0,1,0.75`（上寄せ）や `crop=0,0.25,1,1`（下寄せ）で切り出す
- そういう写真にはパンチインや横のパンを使わない（拡大でさらに切れる）。`kb=in` のゆっくり寄るだけにする
- 集合写真の端の人を切り出すときは `crop=x0,y0,x1,y1`（幅 0.36 なら約2.8倍 → 上限 2.4倍）。2.4倍で元の画素の 1.2倍なので、わずかにぼける程度

## プライバシー

- **生徒の写真を外部のサービス（画像生成 AI を含む）に送らない**。コンタクトシートも同じ
- 生成画像（背景）は人物を含めないプロンプトで作る。実在の校舎に似せない（違って見えるのを避けるため、建物を描かせない）
- クラス以外の人（来訪者・他校の生徒）が大きく写る写真は、上映の範囲を依頼者に確かめる
- 名簿との照合（全員が写っているかの確認）は、依頼者が求めない限り行わない

## 写真 ID の扱い

- ID は `<行事の key の頭2文字>-<行事の中の連番>`（`04-123`）。連番はファイル名の順
- ID からファイルを引くときは `data/photo_stats.csv` の `id` 列を使う（`photos.csv` の行の順番は ID と一致しない）
- 行事を足しても既存の ID は変わらない（新しい行事は新しい key になる）
