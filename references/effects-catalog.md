# 演出カタログ

演出は「どこで・なぜ使うか」と一緒に選ぶ。全部を使う必要はない。曲と素材に合わないものは外す。
各演出は、`show.json`・`selection.csv` のどこに書けば実装されるかも示す（実装はスクリプトが行う）。

| ID | 演出 | 使う場面と理由 | 実装（どこに書くか） | 値と注意 |
|---|---|---|---|---|
| E-01 | Ken Burns（ゆっくり寄る・引く・横に流す） | すべての写真。静止画に動きをつけて「映像」にする | `selection.csv` の `kb`（in / out / lr / rl） | 1秒あたり2%（上限 1.10倍）、横は 40px/秒。**補間は線形**（イーズをかけると、カットのたびに止まって見える）。構図（顔の位置）を見て写真ごとに選ぶ。走る・投げる写真は動きの方向に流す |
| E-02 | クロスディゾルブ | 静かな区間（イントロ・Aメロ・間奏・Cメロ・アウトロ）。時間の流れをやわらかく見せる | `transitions.dissolve_long`（2拍 = 28f）・`dissolve_short`（半拍 = 7f）。区間どうしは `sections[].in: dissolve` | 中央を小節の頭に置く。重なっている間も Ken Burns を止めない（スクリプトがキーフレームを延ばす） |
| E-03 | 拍に合わせたカット | サビ・ラスサビ | `transitions` に書かない小節は、すべてカット | 拍の1フレーム前（`cut_offset`） |
| E-04 | 白フラッシュ | サビ1の頭。曲の最初の爆発 | `transitions.flash`、`sections[].in: flash` | 白の頂点を1拍目に。4フレームで上げて8フレームで消す。FilmCraft は線形光で合成するので、不透明度 60% で見た目の明るさ約85%（暗い部屋の大画面で真っ白はまぶしい） |
| E-05 | 章タイトル | 章の頭（2小節） | `graphics.chapters` | 黒 40% の帯（下から 1/4）＋日付 120px＋行事名 56px（丸ゴシック）。横に 40px 流れながらイーズでフェード。左下に置くので、重なる写真は左下に顔がないものを選ぶ |
| E-06 | 1文字ずつ浮かぶタイトル | オープニング・Cメロの見出し・エンディング | `graphics.titles` | 明朝 72px。1文字ずつ、ぼかしが取れながら 28px 下から浮かぶ。出そろったあとも 3% ゆっくり寄る。生成画像の上では暗い暖色の文字＋明るいにじみ（`title_ink`・`title_glow`） |
| E-07 | 3分割コラージュ | サビの中で1回ずつ。縦向きの写真を活かす。単独で見せるほどではない写真をまとめる | `graphics.collages` ＋ `selection.csv` の `collage` 行（2小節、ID を `|` で3つ） | 縦長 632px の3枚が半拍ずつ下から入る |
| E-08 | グリッドの完成 | ラスサビの最後。動画全体の頂点。「一人ひとり」ではなく「みんな」に見せる | `graphics.grid` ＋ `selection.csv` の `grid` 行（cols×rows 枚） | 4小節かけて加速しながら置き、`done_bar` の頭で最後の1枚。少人数・集合の笑顔の写真で埋める。人数にちなんだ枚数にする必要はない |
| E-09 | 色調整（ルック） | 全編に暖色寄りのルックと弱いビネット。静かな区間は彩度を落とし、アウトロは金色寄り | `looks.global`・`looks.sections` | ビネットは −10〜−15 から（−25 は強すぎる）。区間の境目は1小節かけて切り替える。写真ごとの明るさ・色みのばらつきは、区間の中央値から大きく外れたものだけ自動で寄せる |
| E-10 | 写真の補正 | 暗い・傾いた写真 | `selection.csv` の `fix`（`exposure+0.5`）。切り出しは `crop=` | 元の写真は変えない（FilmCraft のクリップ上で補正する） |
| E-11 | 動画クリップ | 半小節の連続のあとの息つぎ。写真では伝わらない動き | `selection.csv` の `video` 行、`note` に `source_in=` | 音は消す。2小節（3.7秒）が基本。素材が短ければ1小節ずつ2本。縦向きは `note` に「縦向き」と書くと背景にぼかしを敷く。編集済みのスライドショー（文字入り）は素材にしない |
| E-12 | シェイク | サビの要所（サビ2の頭、キメ）。スピード感 | `transitions.shake`、`sections[].in: shake` | 全編で8回程度まで。静かな区間とラスサビには使わない。前の写真3フレーム・次の写真4フレームを揺らし、方向ブラーを付ける（標準の Earthquake は使わない） |
| E-13 | フィルムグレイン | 全編。カメラの違う写真の質感をそろえ、拡大の粗さを隠す。懐かしいトーン | `looks.grain`（2〜3） | 20Mbps の H.264 でも粒子は残る |
| E-14 | 光漏れ | 生成画像の登場（オープニング・Cメロ・エンディング） | `graphics.leaks` | 暖色の平面をぼかして横に流し、Screen で重ねる。**文字より下のトラック（V2）に置く**（上に置くと暗い文字が明るく抜けて読めない） |
| E-15 | スピードランプ | 見せ場（ゴール・ジャンプの頂点）を 40% のスローにして拍で戻す | （スクリプト未対応。FilmCraft で手作業） | 60fps 以上の素材だけ（30fps をスローにするとカクつく）。`data/clips.csv` の `slow_ok` |
| E-16 | マッチディゾルブ | アウトロで、最初の集合写真 → 最新の集合写真。時間の経過が重なって見える | `kb_overrides`（2枚の位置と拡大を合わせる）＋ `dissolve_long` | 構図の近い2枚を選ぶ。1枚目を寄せて、2枚目のクラスの大きさに合わせる |
| E-17 | パンチイン | 半小節の連続の中のキメ。写真を替えずにリズムを刻む | `selection.csv` の `punch_in`（何拍目か） | 1.15倍に1フレームで。各区間で2回まで。**顔が端にある写真には使わない**（16:9 に切った時点で頭が切れかけていると、拡大で見切れる） |

## 区間どうしのつなぎ（`sections[].in`）

| 値 | 意味 | 合う場所 |
|---|---|---|
| `cut` | 区間の頭でカット | ラスサビの頭（溜めのあとの強いカット） |
| `dissolve` | マスターで 28 フレームのディゾルブ（区間シーケンスに前後14フレームの余白を持たせる） | 静かな区間に入るところ |
| `flash` | 白フラッシュの下で切り替え | サビ1の頭 |
| `shake` | シェイクで切り替え | サビ2の頭 |
| `under_grid` | グリッドが溶ける下で、次の区間の最初の写真が14フレーム早く始まる | ラスサビ → アウトロ |
